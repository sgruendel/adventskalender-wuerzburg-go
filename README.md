# Go Gin Web Server

This repo can be used as a starting point to deploy [Go](https://golang.org/) web applications on Render.

It is based on the [realtime chat](https://github.com/gin-gonic/examples/tree/master/realtime-advanced) example from the [Gin](https://github.com/gin-gonic/gin) web framework, ported to Go's standard [net/http](https://pkg.go.dev/net/http) package.

The sample app is up at https://go-gin.onrender.com.

## Deployment

See the guide at https://render.com/docs/deploy-go-gin.
